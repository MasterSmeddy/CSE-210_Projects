Hello!

My open-ended project is a Warhammer 40k Army Viewer program, where you
can view armies, learn fun facts about them, and see if they get along.

Users can go through the menus to select from three factions and their
subfactions/armies. Selecting them will display a small description
with additional facts about the selected army.

Users can also enter the names of two armies in the "Who Gets Along"
section (per Brother Tuck's advice), where it will return the status of
whether or not the inputted armies get along or not.
